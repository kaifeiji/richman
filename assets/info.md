# 环球大富翁照片资料整理

> 本文档根据 `assets/` 中的照片逐项转录，照片仅作为规则与数据参考，不作为网页素材。照片存在旋转、裁切、反光和遮挡；无法可靠辨认的内容标记为“待确认”，不要把猜测直接写进游戏规则。

## 一、游戏定位与组件

- 游戏名称：环球大富翁 / Around the World。
- 目标：玩家在世界旅行路线中购买国家土地、建设房屋、收取访客费用，最终成为资产最多/最后未破产的玩家。
- 照片中可辨认组件：
  - 世界旅行棋盘。
  - 国家卡（每个国家对应一张地产卡）。
  - 黄色机会卡。
  - 红色事件卡。
  - 彩色玩家棋子。
  - 纸币、骰子、房屋/建筑标记。

## 二、国家卡字段定义

国家卡上的金额含义必须严格区分：

| 卡面字段 | 游戏含义 |
| --- | --- |
| 所有权 | 购买该国家土地所需支付的费用。购买后该国家归玩家所有。 |
| 访客通关费 | 土地没有建筑时，其他玩家经过该国家需要支付给土地所有者的费用。 |
| 盖房子费用 | 每盖一层房子的费用；每次建造增加 1 层，最多 3 层。 |
| 访客住宿费 | 已有建筑时，访客到达该国家支付的费用；卡面下方三个数依次对应 1 层、2 层、3 层房屋。 |

照片中反复出现的卡面结构为：

1. 国家名称（中文 + 英文）。
2. 所有权金额。
3. 访客通关费金额。
4. 盖房子费用，通常显示为“金额/每层”。
5. 访客住宿费：1 层、2 层、3 层三个金额。
6. 国家代表性建筑插图与地区颜色。

### 住宿费数字的统一记录方式

实现时不要把住宿费误当成建房费用：

```text
property.ownership  = 所有权 / 购买土地费用
property.passFee   = 访客通关费 / 无房时经过费用
property.buildCost = 盖一层房子的费用
property.stayFees  = [1层住宿费, 2层住宿费, 3层住宿费]
```

## 四、玩法说明

### 开局

- 每位玩家获得初始资金；照片说明出现“每人 ¥26000”的总资金/起始资金提示。
- 玩家选择一个棋子。
- 所有棋子从出发点开始。
- 由玩家轮流掷骰子并按点数移动。

### 回合流程

1. 当前玩家掷骰子。
2. 按骰子点数顺时针移动相应格数。
3. 经过出发点时领取出发点奖金（照片可辨认为 ¥2000）。
4. 根据落点执行国家、机会、事件、税务局、环保、股市、避风港、逮捕等格子的效果。
5. 到达未拥有的国家土地时，可以支付所有权费用购买。
6. 到达自己拥有的土地时，可以按规则支付盖房子费用建造房屋。
7. 到达他人拥有的土地时，支付访客通关费或对应层数的访客住宿费。
8. 完成当前玩家动作后，交给下一位玩家。

### 购买土地

- 玩家到达未被占有的国家土地时可购买。
- 支付的是国家卡上的“所有权”，不是访客通关费，也不是盖房子费用。
- 购买后取得该国家所有权，并可在后续规则允许时建房。
- 若资金不足，不能购买。

### 建造房屋

- 建造必须在自己拥有的国家上进行。
- 每次支付该国家卡上的“盖房子费用”，只增加一层。
- 最多建造 3 层。
- 说明页强调：房屋按层数增加；3 层后不能继续增加。
- 房屋/建筑标记有不同颜色或等级，网页实现可用 1、2、3 层视觉标记代替照片。

### 访客收费

- 没有房屋：收取国家卡上的访客通关费。
- 有 1 层房屋：收取访客住宿费第 1 个数字。
- 有 2 层房屋：收取访客住宿费第 2 个数字。
- 有 3 层房屋：收取访客住宿费第 3 个数字。
- 费用支付给土地所有者，不支付给银行。
- 访客本人资金不足时，按说明书的破产/资产处理规则执行。

### 机场

- 棋盘环形路线中没有机场格。中心飞机图案属于组件区，第一版不实现机场传送。

## 五、说明页中能辨认的补充规则

### 投资环保项目

- 到达环境保护格后掷骰：
  - 点数 1、2、3：垃圾处理系统升级，支付 ¥2000。
  - 点数 4、5、6：开发绿色能源，向银行领取补贴 ¥3000。

### 股市

- 到达股市格后掷骰：
  - 点数 1、2：熊市，支付 ¥1000。
  - 点数 3、4：休市，暂停一回合。
  - 点数 5、6：牛市，向银行领取 ¥1500。

### 税务局

- 到达税务局后掷骰：
  - 点数 1、2：税务罚款，支付 ¥2500。
  - 点数 3、4：办理业务，暂停 2 回合。
  - 点数 5、6：获得退税 ¥3000。

### 避风港与逮捕

- 避风港用于规避或处理危险事件/逮捕状态。
- 被逮捕后不能按普通移动流程行动。轮到该玩家时，可以使用免费获释卡；否则本回合停止行动，其他玩家正常继续。
- 被逮捕期间，该玩家拥有的国家不收取访客通关费或住宿费。
- 玩家位于避风港时，其拥有的国家仍正常收取访客通关费或住宿费。
- 游戏没有支付现金保释的机制。

### 破产与胜负

- 玩家无法支付应付费用时进入破产处理。
- 资产/土地/房屋应按照说明规则处理，不能只把现金强制设为 0 而保留全部资产。
- 其余玩家继续游戏。
- 最后仍有资产/未破产资格的玩家获胜；说明页还出现“每个城市拥有最多房产的玩家获得游戏胜利”的相关文字，胜利条件需要确认是“最后存活”还是“城市房产最多”，或两者择一。

## 六、实现时必须遵守的字段与规则约束

- 不使用棋盘照片、国家卡照片、说明照片作为网页视觉素材。
- 国家卡数据必须是唯一数据源；棋盘国家格和国家卡详情共用同一对象。
- 不得用旧字段 `price` 同时表示所有权、通关费或建房费。
- 推荐字段：

```js
{
  type: 'property',
  country: 'Japan',
  name: '日本',
  ownership: 1800,
  passFee: 900,
  buildCost: 1000,
  stayFees: [2600, 4300, 6600],
  buildings: 0
}
```

- `stayFees[0]`、`stayFees[1]`、`stayFees[2]`分别代表 1、2、3 层住宿费。
- 买地扣 `ownership`。
- 盖一层扣 `buildCost`，最多 3 次。
- 无房落地收费 `passFee`。
- 有房落地收费 `stayFees[buildingLevel - 1]`。
- 建房费永远不能作为访客费用收取。
- 机会卡和事件卡必须分组保存，卡面文字与动作效果一一对应。
- 对照片无法确认的金额/文字，先在网页中显示“待确认”或保留数据占位，不得伪造为确定规则。
